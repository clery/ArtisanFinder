# ArtisanFinder changelogs

Release histories are maintained separately for each client:

- [Retail changelog](https://github.com/clery/ArtisanFinder/blob/HEAD/CHANGELOG_RETAIL.md)
- [Forever changelog](https://github.com/clery/ArtisanFinder/blob/HEAD/CHANGELOG_FOREVER.md)

The in-game changelog shows the current client's history. The combined release includes both histories; separate flavor downloads include only their own.

The release workflow replaces this index with the latest notes from both flavors before uploading to release services. For a local BigWigs build, run `python3 Tools/release_changelog.py` first.
